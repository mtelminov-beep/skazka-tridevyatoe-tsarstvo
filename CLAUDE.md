# Проект «Тридевятое царство»

Интерактивная панель 75″ (вертикальная) по русским народным сказкам для детской
библиотеки нового поколения. Аудитория — от 0 до 17 лет, тридцать сказок
на шести возрастных полках.
Frontend — React 18 + TS + Vite (порт 5275), backend — Node + Express с CMS (порт 8803).

Панель собрана как соседняя панель «Лукоморье» (`C:\dev\pushkin`): та же архитектура,
те же имена файлов и классов, тот же журнал версий. Различаются контент, палитра
и два раздела: вместо биографии поэта и подборки строк здесь возрастные полки
и раздел о самой сказочной традиции — у народной сказки автора нет.

## Журнал версий — обязательно

Над репозиторием параллельно работают Claude Code, Codex и Cursor — **на разных
компьютерах**. Общая копия одна: репозиторий на GitHub. Локальная папка — временная
копия, работа считается сделанной только после того, как уехала на GitHub.
Полные правила: **[AGENTS.md](AGENTS.md)**. Подробности по журналу: скилл `version-log`.

**Перед началом работы:**

```bash
node scripts/version.mjs sync
```

**После каждого завершённого изменения:**

```bash
node scripts/version.mjs bump --agent claude --type patch -m "что сделано"
```

**Перед тем как закончить сессию:**

```bash
node scripts/version.mjs status
```

`bump` сам подтягивает чужие версии, считает номер, пишет журнал, коммитит, ставит тег
и пушит на GitHub; при чужом пуше повторяет попытку через rebase. Каждая запись —
**номер · дата и время · агент · что сделано** (машина пишется автоматически).
Номера версий и файлы `VERSION`, `.versions/*`, `CHANGELOG.md` руками не правь.

`status` должен закончиться чисто. Если он ругается на незакоммиченные правки,
неотправленные коммиты или теги — сначала заверсионируй и отправь, и только потом
отчитывайся человеку. Если отправить не удалось (нет сети, конфликт), скажи об этом
прямо: версия осталась только на этой машине. `git push --force`, `--amend` и rebase
опубликованных коммитов запрещены — на других машинах это ломает копии.

## Правки из Chrome

Перед своей правкой после `sync` проверь `git status --short`. Человек может менять
проект через ChatGPT-надстройку в Chrome, и такие изменения часто остаются без `bump`.
Если видишь чужие незакоммиченные правки, сначала изучи `git diff`, не затирай их и,
если они завершены и сборка проходит, оформи отдельной версией:

```bash
npm --prefix frontend run build
node scripts/version.mjs bump --agent chrome --type patch -m "что изменено через Chrome"
```

Тип версии выбирай по смыслу (`patch`, `minor`, `major`). Если правки незавершённые
или сборка падает, остановись и сообщи человеку, что рабочее дерево нужно разобрать.

## Команды

```bash
npm run install:all      # установка зависимостей
npm run dev:api          # бэкенд 8803
npm run dev:web          # фронтенд 5275
npm run build            # сборка + строгая проверка типов
npm run kiosk            # сборка и запуск в режиме киоска с одного порта
```

Порты переопределяются переменными `API_PORT` и `WEB_PORT`. Значения 5275/8803
выбраны так, чтобы не пересекаться с «Лукоморьем» (5274/8802): обе панели
нередко крутятся на одной машине.

## Где что

- `frontend/src/data/` — **весь контент панели**, правки текстов сюда
- `frontend/src/data/tales/` — сказки по возрастным полкам, `age0` … `age5`
- `frontend/src/pages/` — страницы разделов
- `frontend/src/components/games/` — шесть игр
- `frontend/src/admin/` — редакторы CMS, админка на `/admin`
- `frontend/src/styles/folk.css` — компоненты, которых нет в оболочке «Лукоморья»
- `frontend/public/covers/` — обложки сказок и фон заставки
- `backend/src/catalogKeys.js` — список ключей каталогов CMS
- `scripts/version.mjs` — журнал версий

## Аудио

Тексты сказок целиком в код **не пишем**. Основной способ познакомиться со сказкой
на панели — аудиозапись; библиотека загружает файлы через админку, поле `audio`
у сказки до этого пустое, и читалка честно пишет, что запись ещё не загружена.
Поле `text` — короткий пересказ-опора для взрослого, который читает вслух,
а не полная запись сказки.

## Грабли, на которые уже наступали

- `position: fixed` внутри страниц ломается: `.page-enter` (анимация с `transform`)
  и `.glass` (`backdrop-filter`) создают containing block. Оверлеи — только через
  `createPortal` в `document.body`, фон — отдельный fixed-слой `.sky`.
- В CSS-гриде `::before` считается элементом сетки. Если в разметке уже два ребёнка,
  а в CSS два столбца, третий элемент уедет на новую строку. Так сломались
  `.plot__step` и `.fact-list li`.
- Заглушка картинки `.media-fallback` наследует `font-size` контейнера. Свой кегль
  ей задавать нельзя — компонент используется и в обложке сказки (6rem),
  и в кружке героя (2.2rem).
- Карточка сказки — не кнопка, а `div`: внутри две кнопки, «открыть» и «в избранное»,
  а кнопку в кнопку вкладывать нельзя. Вся площадь отдана `.tale-card__open`.
- В игре «Кто лишний» варианты **не перемешиваются**: номер лишнего лежит в `odd`,
  и перетасовка сделала бы его недействительным. Разнообразие — за счёт того,
  что в каталоге лишний стоит на разных местах.
- Маршрут галереи — `/gallery`, не `/media`: путь `/media` занят раздачей
  загруженных файлов, и при перезагрузке страницы запрос ушёл бы на бэкенд.
- Сервер проверяет `frontend/dist` при старте. Собрали фронт после запуска —
  перезапустите сервер, иначе панель не будет раздаваться.
- Имена CSS-переменных (`--sea-*`, `--night-*`, `--oak-*`) унаследованы от «Лукоморья»
  намеренно: сменились только значения. Это позволяет переносить правки стилей
  между панелями, не переписывая CSS. Не переименовывай их «для порядка».

## Новый раздел контента

Тип в `types.ts` → данные в `data/` → ключ в `data/defaults.ts` **и**
в `backend/src/catalogKeys.js` → страница и маршрут. Редактор админки
универсальный, писать свой не нужно.

## Договорённости

Комментарии и интерфейс — по-русски. Комментарий объясняет «почему», а не
пересказывает код. Не коммитить `backend/data/cms-state.json` и `media/uploads/*`.

Контент про сказки — только проверяемые сведения. Народная сказка существует
в десятках вариантов: если в пересказе выбран один из них, это нормально,
но выдавать частный вариант за единственный нельзя. Сверка — по открытым
источникам из раздела «Галерея» (собрание Афанасьева, Викитека, Викисклад,
«Культура.РФ»).
