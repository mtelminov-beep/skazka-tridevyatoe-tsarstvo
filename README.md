# Тридевятое царство

Интерактивная библиотечная панель о русских народных сказках для детей 0–17 лет.

В проекте есть 30 сказок на шести возрастных полках, поиск, избранное, читалка с пересказом и вопросами, CMS для замены материалов и заготовленные места для аудиофайлов.

## Запуск

Требуется Node.js 20+.

```powershell
npm run install:all
npm run dev:api
npm run dev:web
```

Откройте адрес, который покажет Vite (по умолчанию `http://localhost:5275`). Аудио можно добавлять через админ-панель `/admin` или положить в `frontend/public/audio/` и задать путь в каталоге.

## Источники

Народные сюжеты имеют множество вариантов. Контент в проекте — оригинальные краткие пересказы по мотивам фольклорных публикаций, а не репродукция конкретного издания. Для сверки использовались открытые коллекции «Культура.РФ» и академические/цифровые издания сборника А. Н. Афанасьева. «Сказка о мёртвой царевне» отдельно отмечена как литературная сказка А. С. Пушкина.

## Структура

- `frontend/` — React/Vite-интерфейс;
- `backend/` — CMS API и хранилище;
- `frontend/src/data/tales/age0.ts` — расширенные тексты первых пяти сказок;
- `frontend/src/data/defaults.ts` — стартовый каталог всех сказок.
