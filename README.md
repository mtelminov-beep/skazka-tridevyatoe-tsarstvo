# «Тридевятое царство» — интерактивная панель по русским народным сказкам

Панель 75″ в вертикальной ориентации для детской библиотеки нового поколения.
Тридцать русских народных сказок на шести возрастных полках — от «Курочки Рябы»
для двухлетнего до «Марьи Моревны» для подростка. Сказку слушают в записи,
читают вслух по пересказу, разбирают по шагам, ищут в словаре непонятные слова
и играют в шесть игр по её мотивам.

Панель работает без интернета: весь контент лежит внутри, а библиотекарь правит
его через встроенную CMS, не открывая код.

Панель собрана как соседняя панель «Лукоморье» (сказки А. С. Пушкина): та же
архитектура, те же имена файлов и классов, тот же журнал версий. Различаются
контент, палитра и два раздела — вместо биографии поэта и подборки строк здесь
возрастные полки и раздел о самой сказочной традиции. У народной сказки автора нет.

## Над проектом работают несколько агентов

Claude Code, Codex и Cursor правят репозиторий параллельно и **с разных компьютеров**.
Общая копия одна — репозиторий на GitHub; локальная папка всегда временная.

```bash
node scripts/version.mjs sync                                   # перед началом работы
node scripts/version.mjs bump --agent <имя> -m "что сделано"    # после изменения
node scripts/version.mjs status                                 # перед концом сессии
```

`bump` подтягивает чужие версии, считает номер, пишет журнал, коммитит, ставит тег
и пушит. `status` должен закончиться чисто — иначе работа не видна остальным.
Полные правила: [AGENTS.md](AGENTS.md). Для Claude Code: [CLAUDE.md](CLAUDE.md).

Файлы `VERSION`, `.versions/*` и `CHANGELOG.md` ведутся скриптом. Руками не править.

## Быстрый старт

Нужен Node.js 20+.

```bash
npm run install:all      # зависимости фронта и бэка
npm run dev:api          # CMS API на 8803
npm run dev:web          # панель на 5275
```

Панель — `http://127.0.0.1:5275`, админка — `http://127.0.0.1:5275/admin`
(логин `admin`, пароль `admin`; **смените перед запуском в зале**).

Режим киоска — сборка и раздача с одного порта:

```bash
npm run kiosk            # = npm run build && npm run start
```

### Если порты заняты

На одной машине рядом нередко крутится «Лукоморье» (5274/8802). Порты
переопределяются переменными окружения:

```bash
API_PORT=8813 WEB_PORT=5285 npm run dev:web
```

Vite сам возьмёт следующий свободный порт, если заданный занят (`strictPort: false`).

«Сказка о мёртвой царевне» — литературная сказка Пушкина, и в каталоге она помечена
типом `literary`. Она стоит рядом с народными намеренно: на ней лучше всего видно,
как фольклорный сюжет переходит в литературу.

«Порядок сказки» и «Кто лишний» добавлены под народную сказку специально:
кумулятивный сюжет («Репка», «Теремок») сам просится в игру на порядок,
а постоянный набор предметов у каждого героя — в игру на лишнее.

## Аудио

**Тексты сказок целиком в код не пишутся.** Основной способ познакомиться со сказкой
на панели — аудиозапись. Поле `audio` у сказки пустое, пока библиотека не загрузит
файл, и читалка честно пишет, что записи ещё нет.

Два способа добавить запись:

1. **Через админку** (рекомендуется): `/admin` → раздел «Сказки» → поле «Аудиофайл» →
   загрузить. Файл ляжет в `media/uploads/`, путь подставится сам.
2. **Файлом**: положить в `frontend/public/audio/` и вписать путь вида
   `/audio/kolobok.mp3` в поле `audio` нужной сказки.

Длинную сказку можно разбить на части через `audioParts` — тогда читалка покажет
список с отдельным проигрывателем на каждую часть.

Поле `text` — не полная запись сказки, а короткий пересказ-опора для взрослого,
который читает вслух. В читалке он свёрнут и не мешает.

### Двухслойный контент

Панель работает на двух слоях. Нижний — эталон в `frontend/src/data/`: он
скомпилирован в бандл и доступен всегда. Верхний — то, что библиотека опубликовала
через CMS. При старте панель пытается прочитать разделы с сервера; если сервера нет
или раздел ни разу не публиковали, показывается эталон.

Поэтому панель не ломается ни без сети, ни с пустой базой — в зале это важнее,
чем свежесть контента.

### Публикация с проверкой версии

Редактор запоминает версию раздела, которую видел перед правкой, и отправляет её
вместе с публикацией. Если за это время раздел изменил кто-то другой, сервер
откажет — правки не затрутся молча.

## Админка (CMS)

`/admin`, вход по логину и паролю. Что умеет:

- править **любой** раздел контента универсальным редактором формы —
  он строится по фактической структуре данных, отдельный редактор под новый
  раздел писать не нужно;
- загружать изображения, аудио и видео в медиатеку;
- откатывать раздел к эталонному контенту;
- выгружать и загружать полную резервную копию (zip: каталоги + файлы);
- показывать счётчики посещений разделов и открытий сказок.

### Смена пароля перед запуском в зале

Логин и пароль по умолчанию — `admin` / `admin`. Перед установкой панели задайте свои
переменными окружения бэкенда:

```bash
CMS_ADMIN_USER=bibliotekar CMS_ADMIN_PASSWORD=длинный-пароль npm run start
```

### Что заполнить перед открытием

Раздел «Библиотека и афиша» намеренно содержит заглушки-образцы: адрес, телефон,
часы работы и ссылку на сайт нужно заменить своими. Афиша встреч и услуги —
рабочие примеры, их стоит привести к тому, что библиотека действительно проводит.

## Решения, принятые под вертикальную панель 75″

- **Навигация внизу.** Панель стоит вертикально, и верхняя половина экрана для
  ребёнка недосягаема. Всё, что нажимают, живёт в нижнем доке.
- **Зона касания от 5.2rem.** Считалась под палец трёхлетнего, а не под курсор.
- **Кегль тянется за вьюпортом.** `font-size` корня завязан на `vw`/`vh`, вся вёрстка
  на `rem` — одна и та же разметка работает и на 4K-панели, и на ноутбуке.
- **Крупный текст кнопкой в шапке.** Библиотекарь включает его слабовидящему читателю
  и выключает после; меняется только базовый кегль, вёрстка подстраивается сама.
- **Тёмная тема основная.** На большом экране она меньше слепит, а золото и киноварь
  на тёмном звучат так же, как на лаковой шкатулке. Светлая — для залов с окнами.
- **Возврат на заставку по бездействию.** Через заданное в CMS время панель сама
  возвращается на приглашающий экран.
- **Нет масштабирования жестами.** «Щипок» и двойной тап отключены — иначе панель
  за день уезжает в непредсказуемый зум.

## Как добавить новый раздел контента

1. Тип в `frontend/src/types.ts` и ключ в `CatalogMap`.
2. Данные в `frontend/src/data/<раздел>.ts`.
3. Ключ в `frontend/src/data/defaults.ts` (плюс подпись и подсказка для админки).
4. Тот же ключ в `backend/src/catalogKeys.js` — иначе публикация вернёт 404.
5. Страница в `frontend/src/pages/` и маршрут в `frontend/src/router.tsx`.
6. Пункт навигации в `frontend/src/data/shell.ts`.

Редактор админки универсальный — писать свой не нужно.

## Грабли, на которые уже наступали

- `position: fixed` внутри страниц ломается: `.page-enter` (анимация с `transform`)
  и `.glass` (`backdrop-filter`) создают containing block. Оверлеи — через
  `createPortal` в `document.body`.
- В CSS-гриде `::before` считается элементом сетки: два столбца + два ребёнка +
  псевдоэлемент = третий уезжает на новую строку.
- `.media-fallback` наследует `font-size` контейнера — свой кегль ей задавать нельзя.
- Карточка сказки — `div`, а не кнопка: внутри две кнопки, «открыть» и «в избранное».
- В игре «Кто лишний» варианты не перемешиваются: номер лишнего лежит в данных.
- Маршрут галереи — `/gallery`, не `/media`: `/media` занят раздачей загруженных файлов.
- Сервер проверяет `frontend/dist` при старте: собрали фронт после запуска — перезапустите.
- Имена CSS-переменных (`--sea-*`, `--night-*`, `--oak-*`) унаследованы от «Лукоморья»
  намеренно — сменились только значения. Это позволяет переносить правки стилей
  между панелями.

## Лицензия и источники

Тексты русских народных сказок относятся к общественному достоянию. Пересказы,
описания героев, словарные статьи, вопросы и факты в этом репозитории написаны
для проекта и опираются на открытые источники:

- «Народные русские сказки» А. Н. Афанасьева — Викитека, Российская государственная
  библиотека, Президентская библиотека;
- иллюстрации И. Билибина, В. Васнецова и других художников — Викисклад
  (общественное достояние, авторы умерли более 70 лет назад);
- В. Я. Пропп, «Морфология сказки» — для раздела о традиции;
- портал «Культура.РФ» — статьи, аудиозаписи и фильмы-сказки.

Народная сказка существует в десятках вариантов. Пересказы в панели следуют одному
из распространённых вариантов и не выдают его за единственно верный; расхождения
с другими изданиями — норма, а не ошибка.

Изображения и аудио в комплект не входят: библиотека загружает свои через админку.
